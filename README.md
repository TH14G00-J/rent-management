# Rent Management

Este projeto foi desenvolvido em Java como parte de um exercício para praticar **Arrays** e **Orientação a Objetos (OO)**.

## 📌 Descrição
O programa simula o gerenciamento de aluguel de quartos em um pensionato.  
Existem 10 quartos numerados de 0 a 9, inicialmente todos vazios.  
O usuário informa quantos estudantes irão alugar os quartos e, para cada estudante, fornece:

- Nome
- Email
- Número do quarto (entre 0 e 9)

Ao final, o programa imprime a lista de quartos ocupados, em ordem crescente do número do quarto.

## 🚀 Tecnologias utilizadas
- Java
- Programação Orientada a Objetos
- Arrays

## 📂 Estrutura
- `Application.java` → Classe principal que executa o programa.
- `entities/Rent.java` → Classe que representa o aluguel, armazenando nome e email do estudante.
